# XiotBox Agent Instructions

This repository is the public XiotBox download/publishing surface.

- Development/publishing trunk: `main`
- Do not use this repository as a source-code development baseline.
- Published artifacts must be traceable to an exact source repository commit or release tag.
- Do not overwrite stable artifacts silently; publish a new version or explicitly documented replacement.
- Do not commit signing keys, tokens, deploy keys, passwords, or private build material.
- Verify checksums and provenance before publishing release artifacts.
- Check `xiotbox-dev/docs/ACTIVE_BASELINES.md` before publishing artifacts built from XiotBox source repositories.
